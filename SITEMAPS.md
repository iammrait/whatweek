# Sitemap and Canonical URL Policy

## Canonical URL scope

The canonical URLs for WhatWeek.ca are clean paths without query parameters.

- Locale roots: `/en`, `/fr`
- Current week pages: `/en/current-week-number-canada`, `/fr/current-week-number-canada`
- ISO overview pages: `/en/iso-week-number-canada`, `/fr/iso-week-number-canada`
- Calendar pages: `/en/calendar/[year]`, `/fr/calendar/[year]`
- Week detail pages: `/en/week/[year]/[week]`, `/fr/week/[year]/[week]`

Query-string variants (for example `?system=iso`, `?province=...`, `?year=...`) are not canonical and are intentionally excluded from sitemaps.

On locale home pages:

- Canonical always points to `https://whatweek.ca/en` or `https://whatweek.ca/fr`
- Any request with search params is served with `robots` set to `noindex,follow`

## Sitemap structure

URLs are generated by `src/app/sitemap.ts` using App Router metadata routes with `generateSitemaps`. Next.js exposes each bucket at `/sitemap/{id}.xml` only. A separate index handler cannot live at `app/sitemap.xml/route.ts` because it conflicts with the metadata `sitemap.ts` convention, so the index is implemented at `src/app/sitemap-index/route.ts` and mapped to `/sitemap.xml` via a rewrite in `next.config.ts`.

- Sitemap index URL: `/sitemap.xml` (rewritten internally to `/sitemap-index`)
- Child sitemap pattern: `/sitemap/[id].xml` (from `generateSitemaps` in `src/app/sitemap.ts`)
- Buckets:
  - `base`: core canonical pages for each locale
  - `en-<year>` and `fr-<year>`: one sitemap per locale-year containing:
    - `/[locale]/calendar/[year]`
    - all valid `/[locale]/week/[year]/[week]` URLs

This keeps each sitemap far under search-engine limits (50,000 URLs per file).

## Year range maintenance

The sitemap year range is controlled by constants in `src/app/sitemap.ts`.

- `MIN_YEAR = 1900`
- `MAX_YEAR = 2100`

To extend coverage in future years, update `MAX_YEAR` (and optionally `MIN_YEAR` if needed), then redeploy.

Week URL counts per year are derived from `getWeeksInIsoYear(year)` in `src/lib/week.ts`, so each year only emits valid week numbers.

## Robots and submission

`src/app/robots.ts` points search engines to the sitemap index at `https://whatweek.ca/sitemap.xml`.

After deployment:

1. Open `https://whatweek.ca/sitemap.xml` and sample child sitemap URLs.
2. Submit the sitemap index in Google Search Console.
3. Re-run Ahrefs Site Audit to confirm week/calendar URL coverage.
